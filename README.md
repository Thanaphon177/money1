# 🐧 เพนกวินออมเงิน

เว็บบันทึกรายรับรายจ่ายส่วนตัว ธีมสีฟ้าน่ารัก ใช้งานบนมือถือเป็นหลัก

## ฟีเจอร์
- บันทึกรายรับ/รายจ่าย เลือกหมวดหมู่ด้วยปุ่มอีโมจิ
- ดูยอดคงเหลือ รายรับ รายจ่ายรายเดือน เลื่อนดูเดือนอื่นได้
- รายการจัดกลุ่มตามวัน ลบได้
- สรุปรายจ่ายแยกตามหมวด
- คัดลอกข้อมูลเป็น CSV
- รองรับโหมดมืดตามเครื่อง
- ไม่ต้องมี backend ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์

> ข้อมูลอยู่เฉพาะเครื่องและเบราว์เซอร์ที่ใช้บันทึก ถ้าล้างข้อมูลเบราว์เซอร์ข้อมูลจะหาย แนะนำให้กด "คัดลอกเป็น CSV" สำรองไว้เป็นระยะ

## โครงสร้างไฟล์
```
money-tracker/
├── index.html   # โครงหน้าเว็บ
├── style.css    # ธีมและแอนิเมชัน
├── script.js    # ตรรกะทั้งหมด
└── README.md
```

## เปิดใช้งานบนเครื่อง
ดับเบิลคลิก `index.html` ได้เลย

## ขึ้นเว็บด้วย GitHub Pages (ฟรี)
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ให้ `index.html` อยู่ที่ราก repo)
2. ไปที่ **Settings → Pages**
3. หัวข้อ **Build and deployment** เลือก Source เป็น **Deploy from a branch**
4. เลือก Branch เป็น `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

เปิดลิงก์นั้นบนมือถือแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" ก็ใช้เหมือนแอปได้

## ปรับแต่ง
- เปลี่ยนสี: แก้ตัวแปรที่ต้นไฟล์ `style.css` (`--pink` คือสีหลัก)
- เพิ่ม/แก้หมวดหมู่: แก้ `CATS` และ `EM` ที่ต้นไฟล์ `script.js`
